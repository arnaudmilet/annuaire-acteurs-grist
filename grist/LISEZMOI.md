# Modèle Grist

Dépose ici le fichier `annuaire_acteurs_modele.grist` exporté depuis Grist :

1. Dans le document Grist d'origine : menu **Partager** → **Dupliquer le document**, coche **En tant que modèle** (on garde la structure, les formules et les pages, sans les données), puis valide.
2. Ouvre la copie et vérifie qu'elle ne contient plus de données. Les référentiels peuvent être conservés.
3. Menu **Partager** → **Télécharger** → **Document (.grist)**.
4. Renomme le fichier `annuaire_acteurs_modele.grist` et dépose-le dans ce dossier.
